**Import Data using Transform Maps**

Platform: ServiceNow

Project Description:
This project demonstrates the process of importing employee data from a spreadsheet into ServiceNow using Import Sets and Transform Maps. The project also demonstrates Coalesce for duplicate prevention, Reports, and an Employee Analytics Dashboard.
